# giza-vdec-reference

This is a public, contaminated reference task for validating the BlobHell-AIBench harness. It is permanently leaderboard-ineligible because prior solution information may be publicly available.

Target metadata describes the Amazon Fire HD 8 (6th generation, `giza`), MediaTek MT8163, LineageOS 17.1 / Android 10, and Linux 3.18. No firmware, vendor blob, DRM component, proprietary library, system image, hidden patch, or reference solution is included.

The v0.1 criteria deliberately label incomplete collectors as semi-automatic or future. A default scripted run does not create evidence and must FAIL.
